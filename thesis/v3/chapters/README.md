# Chapter sources

One HTML fragment per chapter, in file-name order (`00_front.html`,
`01_*.html`, …). `build.py` and `to_latex.py` consume exactly these files.

Conventions:

- citations are `[@bibkey]`, resolved against `../bib/lit_*.json`;
- figures are referenced as `figures/<name>.png` and produced by the two figure
  scripts, never added by hand;
- `_core_tables.html` is generated by `build_core_tables.py` and is overwritten
  on every run — do not edit it;
- `DATA-NEEDED` and `CITE-NEEDED` are the in-text markers for a number or a
  reference that is not yet in place; `build.py` lists them in
  `build_report.json`, and none may remain at submission;
- `00_front.html` carries the thesis data (degree, date, faculty, title,
  authors, supervisor) used by both builders.
